隱私政策

生效及最後更新日期：2026 年 11 月 10 日

1. 適用範圍與管理者

本政策適用於由至聖英文 KungFucius English 粉絲專頁經營者管理的「kungfucius」Facebook 應用程式，以及相關的內部內容製作、發布與成效紀錄工具。本應用程式用於管理經營者有權管理的粉絲專頁，目前不提供其他商家自行註冊或連接粉絲專頁的服務。

2. 處理的資料

依管理員實際授權的權限與 Meta 提供的功能，我們會處理管理員授權資訊與存取憑證、粉絲專頁識別資訊、貼文文字、圖片、影片、替代文字、貼文識別碼、發布時間、公開連結、發布與處理狀態，以及可取得的彙總互動與成效數據，例如回應、留言及分享數量、觸及與觀看資料。權限未開放或無法取得的資料，不視為已取得。

當你透過粉絲專頁聯絡我們或提出資料請求時，我們也會處理你在該次聯絡中提供的帳號名稱、聯絡方式及訊息內容。請勿提供密碼、身分證件或其他與請求無關的敏感資料。

3. 使用目的

資料用於驗證管理權限、製作與發布英語教學內容、檢查發布結果與重複貼文、維護作業紀錄、評估內容成效、排除錯誤，以及回應聯絡或資料刪除請求。我們不出售透過本應用程式取得的個人資料。

4. 儲存、安全與保存

授權憑證由經營者控制的執行環境保存，供程式向 Meta 驗證身分，不會放入公開政策網站。發布紀錄與成效資料保存於經營者管理的檔案與作業環境。目前沒有統一的自動到期刪除排程；經營者依管理、除錯、安全與履行義務的需要檢視保存必要性，並於不再需要時移除相關資料。撤銷 Meta 授權會影響後續 API 存取，但不會自動刪除既有本機紀錄。

5. 服務提供者與資料揭露

使用 Facebook 功能時，相關資料會傳送至 Meta，由其依適用政策處理。公開的隱私政策網站由 GitHub Pages 提供託管；網站存取可能由 GitHub 依其政策記錄。本政策頁本身未加入分析追蹤碼、廣告或資料收集表單。

內容製作流程會使用外部 AI 與技術服務協助撰寫、翻譯及處理教學素材。提供給這些服務的資料應限於完成工作所需的素材；本應用程式的粉專存取憑證不應作為內容素材提供。若法律要求，或為處理安全事件及保護合法權益，我們可能依法揭露必要資料。

6. 你的選擇與資料刪除

管理員可透過 Facebook 的應用程式或商業整合設定撤銷本應用程式授權。若希望查詢、更正或刪除本應用程式保存的個人資料，請透過下方粉絲專頁聯絡入口提出請求，註明「kungfucius 資料請求」，並提供足以辨識相關資料的貼文連結或帳號資訊。我們會在確認請求人有權提出請求後處理；依法必須保存的紀錄除外。

刪除我們保存的資料副本，不代表 Facebook 上的貼文、留言或 Meta 保存的資料會一併刪除；Facebook 平台上的資料也可透過其提供的功能管理。

7. 聯絡方式

資料管理者：至聖英文 KungFucius English 粉絲專頁經營者。
聯絡入口：至聖英文 KungFucius English Facebook 粉絲專頁（請使用粉絲專頁可用的訊息或聯絡功能）。

8. 政策更新

如資料用途、使用功能或處理方式變更，我們會更新本頁與最後更新日期。
